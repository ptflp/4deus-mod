## English

Install the latest stable version of 4deus Mod directly from Decky Loader. No
Desktop Mode or terminal is required.

### Install

Copy this URL:

```text
https://github.com/ptflp/4deus-mod/releases/latest/download/4deusMod.zip
```

Then on your Steam Deck:

1. Open the **Quick Access** menu and select **Decky**.
2. Open **Decky Settings** using the cog button.
3. Under **General**, enable **Developer mode**.
4. Open the new **Developer** tab.
5. Paste the URL into **Install Plugin from URL** and select **Install**.

The URL always downloads the ZIP from the latest stable GitHub release.

ติดตั้ง 4deus Mod เวอร์ชันเสถียรล่าสุดได้โดยตรงจาก Decky Loader
โดยไม่ต้องใช้โหมดเดสก์ท็อปหรือเทอร์มินัล

### การติดตั้ง

คัดลอก URL นี้:

```text
https://github.com/ptflp/4deus-mod/releases/latest/download/4deusMod.zip
```

จากนั้นทำตามขั้นตอนต่อไปนี้บน Steam Deck:

1. เปิดเมนู **Quick Access** แล้วเลือก **Decky**
2. เปิด **Decky Settings** ด้วยปุ่มรูปเฟือง
3. ใน **General** ให้เปิดใช้งาน **Developer mode**
4. เปิดแท็บ **Developer** ที่ปรากฏขึ้นใหม่
5. วาง URL ใน **Install Plugin from URL** แล้วเลือก **Install**

URL นี้จะดาวน์โหลดไฟล์ ZIP ของเวอร์ชันเสถียรล่าสุดจาก GitHub เสมอ

## Türkçe

4deus Mod'un en son kararlı sürümünü doğrudan Decky Loader üzerinden kurun.
Masaüstü Modu veya terminal gerekmez.

### Kurulum

Bu URL'yi kopyalayın:

```text
https://github.com/ptflp/4deus-mod/releases/latest/download/4deusMod.zip
```

Ardından Steam Deck'te:

1. **Quick Access** menüsünü açın ve **Decky**'yi seçin.
2. Dişli düğmesini kullanarak **Decky Settings**'i açın.
3. **General** bölümünde **Developer mode** seçeneğini etkinleştirin.
4. Yeni **Developer** sekmesini açın.
5. URL'yi **Install Plugin from URL** alanına yapıştırın ve **Install**'ı seçin.

Bu URL her zaman GitHub'daki en son kararlı sürümün ZIP dosyasını indirir.

## Українська

Установіть останню стабільну версію 4deus Mod безпосередньо через Decky Loader.
Режим робочого столу й термінал не потрібні.

### Установлення

Скопіюйте це посилання:

```text
https://github.com/ptflp/4deus-mod/releases/latest/download/4deusMod.zip
```

Потім на Steam Deck:

1. Відкрийте меню **Quick Access** і виберіть **Decky**.
2. Відкрийте **Decky Settings** кнопкою із шестернею.
3. У розділі **General** увімкніть **Developer mode**.
4. Відкрийте нову вкладку **Developer**.
5. Вставте посилання в **Install Plugin from URL** і виберіть **Install**.

Посилання завжди завантажує ZIP останньої стабільної версії з GitHub.

## Tiếng Việt

Cài đặt phiên bản ổn định mới nhất của 4deus Mod trực tiếp từ Decky Loader.
Không cần dùng Chế độ máy tính để bàn hoặc terminal.

### Cài đặt

Sao chép URL này:

```text
https://github.com/ptflp/4deus-mod/releases/latest/download/4deusMod.zip
```

Sau đó, trên Steam Deck:

1. Mở menu **Quick Access** và chọn **Decky**.
2. Mở **Decky Settings** bằng nút bánh răng.
3. Trong **General**, bật **Developer mode**.
4. Mở thẻ **Developer** mới xuất hiện.
5. Dán URL vào **Install Plugin from URL** và chọn **Install**.

URL này luôn tải xuống tệp ZIP của bản phát hành ổn định mới nhất từ GitHub.
